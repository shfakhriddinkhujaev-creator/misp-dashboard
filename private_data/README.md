# private_data/

Локальная папка для собственных данных (CSV, Excel, JSON и т.д.).

Всё, что вы сюда положите **на своём компьютере**, git игнорирует
(см. `private_data/.gitignore`): файлы не попадут в коммиты и не будут
загружены на GitHub. В репозитории хранятся только этот README и `.gitignore`.

## Важно

- Репозиторий **публичный**. Не загружайте данные в эту папку через сайт
  GitHub (кнопка «Add file → Upload files») - такие файлы сразу коммитятся
  и становятся видны всем.
- Не используйте `git add -f` для файлов из этой папки - флаг `-f`
  обходит `.gitignore`.
- Проверить, что файл действительно игнорируется:

  ```bash
  git check-ignore -v private_data/имя_файла.csv
  ```

  Если команда выводит строку с `private_data/.gitignore` - файл защищён.
